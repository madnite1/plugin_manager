시간 (최소 1, 최대 24 — 기본 6)

백그라운드에서 지정된 간격으로 GitHub 토픽 검색을 수행해 카탈로그를 자동 갱신합니다. 변경 사항은 다음 갱신 주기부터 적용됩니다.

한 줄에 하나씩 또는 쉼표로 구분해 입력하세요. 형식: 소문자 영문/숫자/하이픈 (예: bookoasis-plugin). 빈 목록이면 기본값(bookoasis-plugin)으로 복원됩니다.

GitHub 비인증 검색은 분당 10회 제한 — 토픽 수 + 버전 검증 요청 합계가 한도 내여야 합니다. 최대 5개까지 등록할 수 있습니다 (초과분은 저장되지 않습니다).

입력 후 저장하면 GitHub Search API에 Authorization: Bearer 로 전송됩니다. 토큰 사용 시 호출이 공용 IP 기준이 아닌 계정 기준으로 집계되어 클라우드 공용 IP의 403(rate limit)을 피할 수 있습니다. (Search 30회/분, 일반 API 5,000회/시간). 실제 토큰 값은 화면에 표시되지 않으며 저장 여부만 표시됩니다. (토큰 스코프: 공개 저장소 검색이라 특별 권한 불필요 — 권장: fine-grained, "Public Repositories" 읽기)

등록한 Gitea 서버의 토글로 카탈로그 조회 사용 여부를 켜/끕니다. 비활성 서버는 토픽 검색·버전 조회·소스 교체 후보에서 제외됩니다. (토큰 값은 화면에 표시되지 않으며, 저장된 서버는 마스킹으로만 표시됩니다). 등록 목록은 설정 저장 시 반영됩니다.

소스 검증(가이드 §2/§3 규정)에 실패한 플러그인도 설치할 수 있게 합니다. 기본 OFF — 켜면 위험(코어 라이브러리 덮어쓰기, 심볼릭 링크 등)을 감수하고 설치합니다. 켠 상태에서도 설치 시 가이드 위반 항목을 안내하고 계속 여부를 확인합니다.
Git URL 설치 시 update_manifest 가 없는 저장소도 이 옵션이 켜져 있을 때만 전체 파일 복사 방식으로 설치할 수 있습니다 (자동 업데이트 미지원).

켜면 설정된 카탈로그 갱신 간격마다 카탈로그를 새로고침한 뒤, 설치된 플러그인 중 update_manifest 가 있고 새 버전이 있는 것을 자동으로 교체합니다. 기본 OFF — 실서버에서 자동 교체가 부담되면 OFF를 유지하세요. 플러그인 매니저 본인은 자동 업데이트 대상에서 제외됩니다.

켜면 플러그인 카드에 직전 성공 업데이트 이전 버전으로 되돌리는 롤백 버튼을 표시합니다. 기본 OFF — 꺼져 있어도 업데이트 전 코드 백업은 유지되며, 영속 데이터는 롤백하지 않습니다.
